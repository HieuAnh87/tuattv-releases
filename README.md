# Tuất TV — bản phát hành

Ứng dụng Android TV xem kênh truyền hình Việt Nam và bóng đá trực tiếp, dùng trong gia đình.

- **Cài lần đầu:** tải file `TuatTV-x.y.z.apk` ở mục [Releases](../../releases/latest) rồi cài lên TV (ví dụ qua "Send Files to TV" hoặc USB).
- **Các lần sau:** app tự báo khi có bản mới — chọn **Cập nhật ngay**, hoặc vào *Cài đặt › Phiên bản*.

Repo này chỉ chứa file phát hành (APK + `update.json`).
